**위치:** S9 `engine check`의 종료 코드

**무엇이 비어 있었나:** G75가 종료 코드를 CLI의 일로 미뤘고 체계가 없었다.

**어떻게 정했나:** **0** = 오류 없음(경고·정보만 있어도 0), **1** = 모드 콘텐츠에 오류가 있음, **2** = 사용법·환경 문제(잘못된 인자, 없는 모드 폴더 등 진단을 만들기 전에 막히는 것), **3** = 엔진 내부 예외(엔진 버그). 종료 코드 0과 JSON의 `ok`=true는 항상 같이 간다. 경고를 오류로 올리는 옵션이 생기면 올린 뒤의 심각도로 `ok`와 종료 코드를 정한다.

**이유:** 1은 모드를, 2는 명령을, 3은 엔진을 고치라는 뜻이라 CI와 모더의 대응이 다르다. pyright·ESLint처럼 작은 번호가 CI 설정에서 익숙하고, sysexits(64·65·70)는 정확하지만 낯설다.
