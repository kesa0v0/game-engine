**위치:** G401에서 이어서: 일괄·단건 경계 메서드의 이름

**무엇이 비어 있었나:** G401은 이름을 구현 때 정한다고 했다. 경계의 공개 API 이름은 호스트가 기대는 계약이다.

**어떻게 정했나 (사용자가 고름):**

- `WorldObjects(since)`: `since`가 0이면 그릴 엔티티 전부, 아니면 그 도장 뒤에 바뀐 것(`Changed`)과 빠진 것(`Gone`: 사라짐, 안 보이게 됨, `look`·`where`가 `None`, G405). 결과의 `Stamp`를 다음에 넘긴다.
- `WorldObject(key, entity)`: 한 엔티티의 그림·자리. 그리지 않을 엔티티면 null.

고른 것: `WorldObjects`(이것), `Shown`(보기 규칙의 "보임"과 헷갈림), `Drawables`(엔진 결정의 "월드" 어휘와 따로 놂).

**이유:** G393 이후 결정과 문서가 "월드 표시"·"월드 물체"라 부르고 `@world_click`·`@world_marks`와 짝이 맞는다. 지도가 아닌 화면(카드 테이블 등)에도 어색하지 않다.

**상태:** 확인
