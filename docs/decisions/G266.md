**위치:** S1 Def id의 이름 공간 ⑦ 짧은 이름을 전체 이름으로 바꾸는 내장 함수 (G261에서 이어짐)

**무엇이 비어 있었나:** G261은 타입을 모르는 자리(`==` 비교, 사전 키)에서 짧은 이름을 쓰려면 불러올 때 내 모드 기준으로 풀리는 함수를 쓰게 했지만 이름은 임시(`defid`)로 두었고, 없는 Def를 받았을 때와 리터럴 검사도 적지 않았다.

**어떻게 정했나:** **이름은 `defid`다**(`u.Ship.kind == defid("Sloop")`, `{defid("Sloop"): 8}`). 인자는 그 코드를 쓴 모드 기준으로 풀고(`:`가 있으면 그대로), 그런 Def가 없으면 실행 오류이고 "혹시 …?" 힌트가 붙는다. 인자가 문자열 리터럴이면 불러올 때 같은 검사를 해서 오타가 로드 오류가 된다. 고르지 않은 것: `def_id`(엔진의 `mod_loaded`처럼 밑줄을 쓰지만 모더가 지역 변수 이름으로 흔히 써서 내장을 가림, G112), `DefId("Sloop")`(주석 자리의 `DefId["Ship"]`과 이름 하나가 두 일을 함).

**이유:** 파이썬 내장도 짧은 이름은 붙여 쓴다(`isinstance`, `getattr`, `frozenset`, 일반 지식). 엔진 내장에도 `contribs`·`randint`처럼 붙인 이름이 이미 있다. RimWorld·패러독스 스크립트에는 이름 공간이 없어 이런 함수가 없다.

**상태:** 확인
