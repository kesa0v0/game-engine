**위치:** X2 `ask`가 시간을 막는지의 기본값

**무엇이 비어 있었나:** X2는 `blocks_time`인 질문이 열려 있으면 `advance`를 거부하고, 막는 질문에 마감을 두면 오류라고만 했다. 아무것도 적지 않은 `ask`가 막는지는 정하지 않았다.

**어떻게 정했나:** **마감 유무로 정한다.** `deadline=`이 없으면 막고 있으면 막지 않는다. `blocks_time=`을 적으면 그것을 따른다(`blocks_time=False`만 쓰면 마감 없이 시간이 흐르는 질문). 막는 질문에 마감을 두는 오류는 둘을 직접 함께 적었을 때만 난다.

**이유:** 기본 막음(A)은 마감을 쓸 때마다 `blocks_time=False`를 함께 적어야 하고 빠뜨리면 오류다. 기본 안 막음(B)은 턴제에서 막기를 깜빡하면 질문을 건너뛴 채 시간이 흐르는데 눈에 띄지 않는다. RimWorld 선택 편지와 패러독스 이벤트는 시간이 흐르며 마감이 있고, 이전 엔진의 `isMandatory`(U10)는 막는 쪽이다. C는 적은 것만 보고 둘을 나눈다.

**상태:** 확인
