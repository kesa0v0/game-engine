**위치:** S1 ④ `parent` 검증

**무엇이 비어 있었나:** `parent`는 ②b에서 이름만 적어 두었고, 어떤 경우가 오류인지 없었다.

**어떻게 정했나:** ④에서 해석하며 다음은 모두 **자식 Def를 쓴 모드의 오류**다: 부모 Def가 없음(“혹시 …?”), 부모가 이 모드에 보이지 않음(`dependencies` 추가 안내), 부모와 자식의 Def 타입이 다름, 부모 체인의 순환(자기 자신 포함, 순환에 든 Def를 모두 표시). 오류가 난 Def의 자식은 연쇄 오류 없이 건너뛴다. `abstract=True`인 Def도 최종 Def 목록에 들어가고 상속의 부모 역할을 하며, 엔티티를 만들 수 없다는 표시만 단다(쓰는 쪽은 런타임).

**이유:** 타입마다 const·컴포넌트가 달라 다른 타입끼리는 값을 물려줄 수 없다. 오류 하나가 자식으로 퍼지면 원인을 찾기 어렵다.

**상태:** 확인
