**위치:** S1 ④ 컴포넌트 값의 상속 병합 단위

**무엇이 비어 있었나:** spec은 컴포넌트 목록이 키 단위로 병합된다고만 했고, 컴포넌트 안의 값을 어떻게 합치는지는 없었다.

**어떻게 정했나:** 컴포넌트는 **값 단위로** 병합한다: 자식이 적은 값만 부모 것을 덮고 안 적은 값은 물려받는다(부모 `Health(base_max=10, regen=2)`, 자식 `Health(base_max=12)` → `Health(base_max=12, regen=2)`). 키 컴포넌트는 키 단위로 합치고 같은 키의 줄은 값 단위로 합친다. const는 spec대로: 안 적으면 물려받고, 적으면 교체(`merge="append"` 리스트는 부모 뒤에 붙임). `inherit.…` 식은 부모의 병합이 끝난 값을 읽고, 부모에 값이 없으면 스키마 `default`를 쓰며, 둘 다 없으면 G56의 오류.

**이유:** const를 상속하는 규칙(안 적으면 물려받음)과 같다. 통째 교체면 값 하나만 바꾸려 해도 나머지를 다시 적어야 하고, 부모가 바뀌면 자식이 조용히 어긋난다.

**상태:** 확인
