**위치:** S5 열린 질문 "`wait` 중 Flow의 취소 규칙 세부"

**무엇이 비어 있었나:** 자는 Flow(예: `wait(ticks=10)` 뒤에 건물을 짓는 건설)를 플레이어가 중간에 취소할 길이 S5에 없다. 지금 Flow가 취소되는 경우는 대상 엔티티가 사라질 때뿐이다(G163~G165).

**어떻게 정했나:** **취소 전용 기능은 두지 않는다.** 취소는 상태로 표현한다: (1) 일을 엔티티(공사 현장)로 두고 `wait(..., about=현장)`으로 잡은 뒤 취소 커맨드가 현장을 지우면 Flow가 깨어나지 않고 취소된다(G163·G165, 기존 테스트 `AboutCatchesAnIndirectSubject`가 커맨드로 지우는 경우를 확인), (2) 취소 커맨드가 값을 세우고 Flow가 깨어난 뒤 보고 끝낸다. 둘 다 저장에 자연스럽게 남는다.

**이유:** 스크립트의 `cancel(flow)`(B)는 Flow를 가리키는 새 값 종류, 그 번호를 둘 곳, 남의 Flow를 지울 권한 같은 규칙이 새로 필요하다. 호스트 API만(C)은 게임 규칙에 쓰지 않으므로 지금 필요 없다. RimWorld 건설은 프레임 같은 상태 오브젝트로 표현하고 취소는 그것을 없앤다(일반 지식). 패러독스의 예약 이벤트는 취소 명령이 없고 뜰 때 조건을 다시 본다(일반 지식).

**상태:** 확인
