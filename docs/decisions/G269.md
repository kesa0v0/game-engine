**위치:** X4 호스트의 번역 API와 번역 다시 읽기 (G254 "엔진 API"에서 이어짐)

**무엇이 비어 있었나:** 번역 어셈블리(G254)를 호스트가 어떻게 부르는지 없었다. 호스트가 글로 바꿔야 하는 것은 셋이다: 스크립트가 만든 쪽지(`require` 메시지·`ask` 제목의 `TextValue`), 화면 값(`view.py`가 돌려주는 dict·list) 안의 맨 값(수·엔티티), 호스트 자신의 글(메뉴 등). 콘솔은 `ValueText.cs`가 키와 인자, `#3 harbor:Sloop`을 그대로 찍었다. 번역 파일을 고친 뒤 다시 읽을 수 있는지도 없었다.

**어떻게 정했나:**

```csharp
var texts = Translations.Load(loadResult, diagnostics);  // 불린 모드들의 locale/
Translator tr = texts.For(new[] { "ko", "en" });         // 플레이어마다, 언어를 바꾸면 새로
tr.Format(textValue);                                    // 쪽지
tr.Value(value, world);                                  // 화면 값 안의 맨 값 하나
tr.Text("kesa-console-moves");                           // 호스트가 키로 직접
tr.Text("harbor-gold", ("n", new IntValue(5)));
tr.DefName("harbor:Sloop");
```

- 결과는 늘 문자열이고 예외를 던지지 않는다. 폴백은 G257(언어 목록 → 주인 모드의 기본 언어 → 키). 번역 오류는 `out` 인자 같은 따로 받는 길로 본다.
- `Value`는 G267 표를 맨 값에도 쓴다. 화면 값 안의 엔티티는 지금 살아 있으니 `world`에서 그 Def를 찾고, 숨김 값은 `kesa-hidden`이다. dict·list를 어떻게 늘어놓을지는 호스트마다 달라 값 하나씩만 바꾼다(`Render(view)` 같은 통째 바꾸기는 두지 않음).
- 호스트는 제 `.ftl` 폴더를 넘길 수 있고 가장 먼저 읽혀 모드가 덮어쓸 수 있다(G256의 "나중이 이김"). 엔진의 `kesa-hidden`도 엔진이 넣는 같은 식의 기본 파일이다. 호스트 키는 `kesa-console-…`처럼 `kesa-` 아래에 호스트 이름을 붙이는 관례다.
- 모드의 화면 파일(`ui/console.txt`)에는 키 부르기를 더하지 않는다. 모드가 화면에 글을 넣으려면 화면 함수가 `text("…")`를 값으로 돌려준다.
- 호스트·모드 코드는 Linguini 타입을 보지 않는다(G254). 언어를 월드에 거는 방식(`world.Language`)은 플레이어마다 언어가 달라 쓰지 않는다.
- **다시 읽기:** `Translations`는 만든 뒤 바뀌지 않는다. 번역 파일을 고치면 호스트가 `Load`를 다시 불러 새 `Translations`로 갈아 끼운다. 그리는 도중에 반쯤 바뀐 글이 섞이지 않고, 새 오류는 진단으로만 받으며 게임은 계속된다(번역 오류는 모드를 끄지 않음, G257). 파일이 바뀌었는지 지켜보는 일은 호스트 몫이다(콘솔이라면 명령 하나). 새 Def는 콘텐츠를 다시 불러야 생기고, 있는 Def의 이름·설명은 번역만 다시 읽어도 바뀐다.

**이유:** 번역은 시뮬레이션 밖이라(X4 P2) 다시 읽어도 월드·저장·결정론에 닿지 않는다. 스크립트·Def의 핫 리로드는 spec대로 후순위다(spine-spec S8 호환성 검사로 길만 열어 둠). 불변 값을 갈아 끼우는 방식은 다시 읽기를 위해 API를 따로 둘 필요가 없다. 사례: 패러독스는 디버그 모드에서 현지화 파일을 게임 안에서 다시 읽는다고 기억하고, RimWorld는 번역을 바꾸면 보통 다시 시작해야 했다고 기억한다(둘 다 확인하지 않음).

**상태:** 확인

**바뀜:** 제목·선택지 자리의 문자열은 키라 `Value`가 아니라 `Label`로 바꾸고, `DefName`·`DefAttr`는 `Label`·`Attr`에 합친다 → G270.

**바뀜:** 엔진·호스트의 번역 키는 `engine-hidden`·`engine-console-…`이다(엔진 예약 이름은 `engine`) → G273.
