**위치:** G303에서 이어서: 데이터 전용 Def를 읽는 함수의 이름, 짧은 이름, 없는 id

**무엇이 비어 있었나:** G303은 Def id에서 가는 내장 함수 하나로 정하고 이름과 작은 것을 미뤘다. 이미 있는 `defid("Medic")`은 이름을 전체 Def id로 바꾼다. 이름 후보는 `defdata`, `def_of`(호스트 C# API `DefOf(엔티티)`와 겹치고 방향이 반대), `getdef`였다. 없는 id는 오류 또는 `None`이었다.

**어떻게 정했나:** 이름은 **`defdata(id)`**. 짧은 이름은 G261대로 지금 도는 스크립트의 모드 기준으로 푼다(`defid()`와 같다). 없는 id는 "혹시 …?"가 붙은 실행 오류다.

**이유:** `defid`(이름 → id)와 `defdata`(id → 데이터)가 짝으로 읽히고 다른 스크립트 내장과 모양이 같다. 없는 const 이름이 오류인 것(G107)과 맞고, Def id는 데이터나 키에서 오는 값이라 없으면 거의 틀림없이 버그다.

**상태:** 확인
