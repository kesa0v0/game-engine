**위치:** S4 생성 순간에 계산하는 기본값의 순서와 실패 (G89·G90 보강)

**무엇이 비어 있었나:** 함수 기본값과 `derived`를 원천으로 하는 `default_from`은 엔티티가 있어야 계산되는데, 한 컴포넌트에 이런 칸이 여럿이면 서로 읽는 순서와 계산이 실패했을 때의 상태가 비어 있었다.

**어떻게 정했나:** 엔티티(컴포넌트, 줄)를 먼저 만든 뒤 이런 칸을 **선언 순서대로 하나씩 계산해 저장**한다. 앞 칸은 뒤 칸이 읽을 수 있고, 아직 계산되지 않은 뒤 칸을 읽으면 “아직 값이 없다”(`RUN007`)로 생성이 실패한다. **계산이 하나라도 실패하면 호출 전체를 되돌린다:** `Create`는 엔티티, 색인, id 증가분까지, `Add`는 붙인 컴포넌트, `AddRow`는 붙인 줄을 지운다. 오류에는 어느 칸의 기본값인지와 생성 맥락이 붙는다. 의존 순서 자동 정렬은 하지 않는다.

**이유:** 규칙이 한 줄이고 오류가 분명하다. 읽는 칸이 실행 중에 정해지므로 자동 정렬은 순환과 비용 문제를 만들고 지금 필요한 근거가 없다. 실패한 호출은 월드를 바꾸지 않는다는 기존 규칙(G91·G93)과 같다.

**상태:** 확인
