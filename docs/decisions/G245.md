**위치:** G244에서 이어서: 호스트가 부를 수 있는 함수의 범위

**무엇이 비어 있었나:** G244는 UI가 보여 줄 값을 모드 스크립트의 순수 함수가 만들고 호스트가 그것을 부른다고 정했다. 호스트가 아무 순수 함수나 부를 수 있는지, UI용으로 표시한 함수만 부를 수 있는지는 없었다.

**어떻게 정했나:** **모드의 아무 순수 함수나 부른다.** 이름은 `모드.함수`(`skirmish.unit_row`)이고 표시 데코레이터는 두지 않는다. 쓰기 함수(G117)·커맨드·핸들러는 부르지 않고 이유를 알려 준다. 순수인지는 모드 로드 때 이미 판정되어 있으므로 부르는 순간 안다. UI 로더가 UI 정의를 읽을 때 그 이름이 부를 수 있는 함수인지 미리 확인할 길을 둔다. 스텁이나 UI 로더용 목록이 필요해지면 표시를 나중에 더할 수 있다.

**이유:** 순수 함수는 불러도 상태를 바꿀 수 없고 순수인지는 커널이 이미 알아서, 표시(`@view`)가 막아 줄 위험이 거의 없다. 표시를 두면 데코레이터가 하나 늘고 도우미 함수(`game()`)도 따로 표시해야 한다. 근거(일반 지식): WoW 애드온의 XML은 아무 전역 Lua 함수나 이름으로 가리키고 따로 표시하지 않는다. CK3 `scripted_gui`는 블록으로 따로 선언하지만 GUI가 효과(쓰기)까지 하기 때문이다.

**상태:** 확인
