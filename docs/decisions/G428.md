---

**위치:** G425에서 이어서: 효과가 위로만 떠오르는 것 말고 비스듬히 날아가거나 커졌다 줄어드는 것

**무엇이 비어 있었나:** 효과 칸은 `fade-in`·`solid`·`fade-out`·`rise`뿐이었다. 옆으로 날아가는 숫자, "팡" 떴다 줄어드는 치명타 숫자를 적을 수 없었다.

**어떻게 정했나 (사용자가 고름):**

- `drift="0.3,0.8"`: 초당 오른쪽 0.3, 위 0.8 공간 단위(`rise`와 같은 방향 규칙). `rise`는 y만 있는 `drift`이고 둘 다 있으면(적거나 묶거나) 로드 문제다.
- `grow="-0.5"`: 크기 배율이 1 + grow × 경과 초이고 0 아래로 가지 않는다. 물체 전체(그 그림의 모든 요소)에 곱한다.
- `bind-drift="dir"`처럼 그림 값으로 덮고, 값이 `None`이면 적힌 값을 쓴다(G425와 같음).

고른 것: 초당 변화량(이것), 시작·끝 값(`move`·`scale-from`·`scale-to`, 수명이 바뀌면 속도가 바뀌고 `rise`와 방식이 갈림), 지금은 넣지 않음.

**이유:** 이미 있는 `rise`와 같은 방식이라 칸 하나를 더 배우면 된다. RimWorld의 mote 정의도 속도와 `growthRate`(초당 크기 변화)를 쓴다(기억에 의한 것, 원문 확인 안 함).

**상태:** 확인
