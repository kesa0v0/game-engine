**위치:** G416에서 이어서: 모드 입력을 어디에 선언하고 기본 키를 어떻게 적나

**무엇이 비어 있었나:** 모드 입력에는 핸들러가 부르는 이름과 기본 키가 붙는다. 키를 읽고 바꾸는 것은 호스트이고 키보드·패드·터치 호스트마다 기본값이 다를 수 있다.

**어떻게 정했나 (사용자가 고름):**

- 이름과 기본 키는 `.input.xml`에 둔다. 공간 `.space.xml`(G411)처럼 Unity 패키지의 형식이고, 다른 호스트는 제 형식으로 둔다.
- 키 표기(`R`, `SHIFT + secondary`)는 그 파일의 일이다. 스크립트는 이름만 쓴다.
- 커널은 이름을 글자로만 맞춘다. 핸들러가 부른 이름이 선언에 없으면 호스트가 로드 때 경고한다.
- 같은 이름의 선언은 나중 모드의 것이 이긴다(`.look.xml`과 같음). 내장 `primary`·`secondary`는 호스트가 안다.

고른 것: 호스트 파일(이것), 스크립트 데이터에 선언(오타를 커널이 잡으나 키보드 표기가 커널 계약이 됨), 데코레이터에 키를 바로(같은 입력의 핸들러끼리 키가 어긋날 수 있음).

**이유:** 키는 호스트가 읽고 바꾸므로 기본값도 호스트 형식에 둔다. G410의 "공간은 호스트 XML"과 같은 기준이다. RimWorld도 `KeyBindingDef`를 XML 데이터에 두고 코드는 이름으로만 쓴다(일반 지식).
