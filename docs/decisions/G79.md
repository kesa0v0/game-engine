**위치:** S9 `engine check`의 출력 형식

**무엇이 비어 있었나:** S9는 “JSON 출력 포함”이라고만 했고 기본 출력과 JSON을 내보내는 곳이 없었다.

**어떻게 정했나:** 기본은 사람용 텍스트를 stdout으로 낸다. 진단 한 줄은 `파일:줄:열: 심각도 코드: 메시지`이고 힌트와 관련 위치는 들여쓴 줄로 붙는다. 순서는 JSON과 같은 정렬이며 끝에 개수 요약과 로드·비활성 모드를 한 줄로 낸다. 정보 진단도 기본으로 보인다(G38의 건너뜀 알림). 텍스트의 파일 경로는 사용자가 준 모드 폴더 경로를 앞에 붙여 현재 폴더 기준으로 낸다(터미널에서 클릭으로 열리게). JSON은 G75대로 모드 폴더 기준이다. `--json`이면 stdout에 G75 JSON 한 덩어리만 낸다. 사용법 오류(종료 코드 2)와 내부 예외(3)의 메시지는 형식과 무관하게 stderr로 낸다. 텍스트 생성도 순수 함수(`CheckReport.ToText`)다.

**이유:** 기본 사용자는 터미널의 모더이고 `파일:줄:열:`은 편집기 터미널에서 클릭된다. 기계는 `--json` 하나로 깨끗한 stdout을 받는다. 텍스트·JSON·종료 코드가 같은 진단 목록과 같은 `ok`(G78)에서 나와 어긋나지 않는다.
