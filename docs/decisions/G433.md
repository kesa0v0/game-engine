**위치:** G391에서 이어서: "버전은 구현할 때 패키지 관리자에서 다시 보고 고정한다"

**무엇이 비어 있었나:** glTF 로더로 glTFast를 쓰기로 했고 버전은 미뤘다.

**어떻게 정했나 (사용자가 고름):**

- `hosts/unity/uk.kesa.engine.unity/package.json`의 의존성에 `"com.unity.cloud.gltfast": "6.20.0"`. 레지스트리에서 본 것: 6.20.0은 2026-08-27, 최소 Unity 6000.0, 의존 burst 1.8.30·collections 2.6.8·mathematics 1.3.3. 데모는 Unity 6000.3.8.
- 실험판 7.0.0-exp.1(2026-08-28)은 쓰지 않는다. 7이 정식판이 되면 옮길지 따로 본다.

고른 것: 6.20.0(이것, 최근 정식판), 6.19.0(한 단계 전), 7.0.0-exp.1(실험판).

**이유:** 우리 Unity 버전에 맞는 가장 최근 정식판이고 G391에서 본 6.15 문서와 같은 6.x 줄이다.

**상태:** 확인
