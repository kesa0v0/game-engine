**위치:** S1 ③ 패치 파일·실행 시점

**무엇이 비어 있었나:** 패치를 적는 파일이 어디인지, ②b가 모든 비스키마 파일을 실행하는데 `patch.*` 호출을 그때 어떻게 다루는지가 없었다.

**어떻게 정했나:** 일반 Def 파일에 쓴다(별도 폴더 규약 없음). ②b에서는 호출을 즉시 적용하지 않고 (모드, 호출 위치, 인자)를 기록만 하며, 인자 모양이 틀리면 그 자리에서 `파일:줄`로 보고한다. ③에서 모든 Def가 등록된 뒤 모드 순서·단계 고정 순서(`set` → `add` → `append` → `remove`)로 적용하고, 대상·필드 오류는 기록해 둔 호출 위치로 보고한다.

**이유:** 패치는 값만 바꾸고 이름 공간은 바꾸지 않아 스키마 단계를 따로 둔 이유(S1)가 적용되지 않는다. 기록 후 적용이면 파일 실행 순서와 무관하고 "대상 없음 = 오류"를 정확히 검사할 수 있다. 즉시 적용(C)은 의존 모드의 Def가 늦게 등록되는 경우를 풀 수 없다.

**상태:** 확인
