**위치:** X4 콘솔 호스트가 플레이어 언어를 받는 법 (G257 "호스트가 넘기는 언어 목록"에서 이어짐, 콘솔 구멍 4번)

**무엇이 비어 있었나:** 번역기는 플레이어의 언어 목록(`["ko", "en"]`)을 호스트에게서 받는다(G257·G269). 콘솔 호스트 `kesa-play`에는 설정 화면이 없어 그 목록을 어디서 얻는지 없었다.

**어떻게 정했나:** **`--lang ko,en`처럼 쉼표로 이은 언어 태그를 받는다. 주지 않으면 OS의 표시 언어(`CultureInfo.CurrentUICulture`) 뒤에 `en`을 붙인 목록이다.** 한국어 Windows면 `ko-KR, en`이고 폴백이 `ko-KR → ko → en`으로 찾는다. 태그가 아닌 값은 사용법 오류(2)다. 테스트는 늘 `--lang`을 준다. 콘솔 자신의 글은 `engine-console-…` 키로 콘솔과 함께 배포하는 번역 폴더에 둔다(G269·G273).

**이유:** 언어는 게임 설정, 곧 호스트의 몫이고 엔진은 어떤 언어도 특별히 대하지 않는다(G257). 터미널 프로그램은 대개 OS 언어(`LANG`)를 따르고 Steam 게임은 Steam이 넘기는 언어를 쓴다(일반 지식). 옵션 없이 고정하면 다른 언어 플레이어가 쓸 수 없고, 늘 `en`이면 OS 설정을 무시한다. 뒤에 `en`을 붙이는 것은 OS 언어의 글이 없는 모드가 주인의 기본 언어까지 가기 전에 영어를 보이게 하려는 것이다(사용자가 추천대로 고름, 2026-10-20).

**상태:** 확인
