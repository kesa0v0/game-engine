**위치:** S9 진단 코드

**무엇이 비어 있었나:** 코드 체계가 열린 질문이었다.

**어떻게 정했나:** 영역 접두사 + 세 자리: `LEX`(렉서), `PAR`(파서), `MOD`(매니페스트·정렬). 영역은 단계가 늘 때 추가.

**이유:** 최소한의 체계로 시작. 이후 모든 단계의 진단이 이 체계를 따랐다(`CMD`·`RUN` 등).

**상태:** 확인 (2026-10-19, 사용자 동의)
