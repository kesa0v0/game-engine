**위치:** S1 `merge="append"` 필드의 `inherit` 식 (G58 보강)

**무엇이 비어 있었나:** `merge="append"` 리스트 필드에 spec 예시대로 `tags = inherit.tags + ["fast"]`를 쓰면 식이 이미 부모 값을 포함하는데 자동 병합이 부모를 한 번 더 붙인다(`a,a,fast`).

**어떻게 정했나:** 필드 값이 `inherit` 식이면 **그 식의 결과를 전체 값으로 본다**: 자동 병합(부모 뒤에 붙임)을 건너뛴다(`a,fast`). 식을 쓰지 않은 리터럴 리스트만 부모 뒤에 붙는다.

**이유:** 작성자가 부모 값을 직접 써서 리스트를 만들었으므로 그 결과가 최종 값이다. 부모 순서를 바꾸거나 일부러 버리는 것도 가능하다.

**상태:** 확인
