**위치:** X2·G126 `on_timeout=`이 가리키는 것

**무엇이 비어 있었나:** X2는 마감이 지나면 엔진이 기본 응답을 넣고 G126은 그때 답한 엔티티가 `None`이며 응답 이름은 `on_timeout`이 정한다고만 했다. 선택지 질문에서 무엇을 가리키는지, 어떻게 적는지는 정하지 않았다.

**어떻게 정했나:** **선택지 값이나 응답 이름으로 가리킨다.** `on_timeout="hide"`는 `choices` 안의 값이어야 하고(같은 값이 여럿이면 앞의 것) 마감이 지나면 `ask`가 그 선택지(`r.choice`·`r.index`)와 `r.by = None`을 돌려준다. `responses=` 질문이면 `on_timeout="Pass"`처럼 응답 이름을 쓰고 `r.response`가 그 이름이며, 응답 커맨드의 본문은 돌지 않는다(인자를 낸 제출자가 없다). 선택지와 응답 이름에 모두 맞거나 어디에도 없으면 실행 오류다.

**이유:** 번호(B)는 선택지 순서를 바꾸면 기본 답이 조용히 바뀐다. 정하지 않고 스크립트가 처리(C)는 spec의 "기본 응답 주입"과 멀고 처리를 빠뜨리면 `None`으로 뒤에서 오류가 난다. 이전 엔진은 선택지에 `isDefault`를 붙였고(U10) EU4 이벤트도 정해진 선택지 하나가 골라진다(세부는 기억 수준).
