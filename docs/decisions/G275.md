**위치:** X4 Def 이름의 번역이 없을 때 (G257 폴백 셋째 "키 자체", 콘솔 구멍 4번에서 드러남)

**무엇이 비어 있었나:** G257의 폴백은 마지막에 키 그대로를 보인다. Def 이름의 키는 `def-harbor-Sloop`(G262)이라 번역 파일이 없는 모드의 엔티티가 화면에 `#3 def-harbor-Sloop`으로 나온다. 모더가 코드에서 쓰는 이름(`harbor:Sloop`)이 아니고 지금 콘솔의 표시보다 읽기 어렵다.

**어떻게 정했나:** **Def 이름의 번역이 어느 언어에도 없으면 Def id(`harbor:Sloop`)를 보인다.** 번역 인자 자리(G267), 제목·선택지 자리(G270), 화면 값 모두 같다. 없는 키라는 번역 오류는 그대로 알린다. 일반 키와 속성(`def-harbor-Sloop.desc`)은 G257대로 키 그대로다.

**이유:** Def id는 모더가 적은 이름이라 번역이 빠진 것을 바로 알아보고, 다른 모드의 같은 이름(`smuggler:Sloop`)과도 구별된다. 경로의 마지막 조각(`Sloop`)은 짧지만 그 구별이 없다. RimWorld도 `label`이 없으면 `defName`을 보인다고 알고 있다(일반 지식, 소스로 확인하지 않음). 사용자가 추천대로 고름(2026-10-20).

**상태:** 확인
