**위치:** S1 매니페스트

**무엇이 비어 있었나:** 모드 id 형식이 없었다.

**어떻게 정했나:** `[a-z][a-z0-9_]*`. 점(`.`)은 쓸 수 없다.

**이유:** 모드 id가 호스트 함수·단계 이름의 네임스페이스 접두사(`core.find_path`)로 쓰이므로 점이 들어가면 모호해진다.

**상태:** 잠정
