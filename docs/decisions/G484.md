**위치:** G419의 받는 순서(커서 아래 엔티티 → 공간)를 끌기에도 쓸지.

**무엇이 비어 있었나:** 누름은 커서 아래 엔티티의 핸들러가 먼저 받는다. 끌기에 그대로 쓰면 지역을 그리다 시작 칸에 부대가 있을 때 다른 핸들러가 받고, G483에 따라 받는 값은 경로뿐이라 어느 엔티티였는지도 모른다.

**어떻게 정했나 (사용자가 고름):**

- 모양 종류가 붙은 입력은 공간 대상만 받는다. 어느 입력에 종류가 붙었는지는 호스트 파일(`.input.xml`)에만 있으므로, 대상이 공간 이름이 아닌 핸들러는 호스트가 로드 때 문제로 알린다(`InputLibrary.CheckHandlers`, G424와 같은 자리).
- 시작한 자리의 공간에서 재고, 다른 공간이나 공간 밖으로 나간 동안의 자리는 값에 넣지 않는다.
- 여러 핸들러는 G420 순서. 도구 고르기(지역 칠하기 중인가 등)는 모드가 화면 상태를 사전 조건으로 둔다.
- 끌어다 놓기처럼 시작이나 끝에 무엇이 있었는지가 필요하면 모드가 첫 자리와 끝 자리로 찾는다.

고른 것: 공간만(이것), 시작 자리 기준으로 G419(엔티티 핸들러가 먼저, 잡은 것의 타입으로 가를 수 있으나 시작 칸에 따라 같은 동작의 결과가 바뀜), 끝 자리 기준(놓은 곳이 받음, 지역 그리기에는 뜻이 없음).

**이유:** 다른 게임의 끌기는 시작점에 무엇이 있었는지가 아니라 범위 안에 무엇이 있는지와 어떤 끌기 상태(도구, 수정 키)인지를 본다(사용자 경험). RimWorld 구역 칠하기, Factorio 선택 도구, HoI4 작전 화살표도 도구를 먼저 고르고 끈다(일반 지식). 엔티티 대상은 지금 문제로 알려 받지 않으므로 나중에 엔티티 기준 받기를 더해도 깨지는 모드가 없다.

**상태:** 확인
