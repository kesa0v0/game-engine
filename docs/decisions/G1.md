**위치:** S1 ① 정렬

**무엇이 비어 있었나:** "의존 관계가 없는 모드끼리는 id 순"을 문자 그대로는 만족할 수 없다. 예: `a`가 `z`에 의존하고 `b`는 무관하면, id 순으로는 a < b < z인데 의존성은 z가 a보다 앞서야 한다.

**어떻게 정했나:** Kahn 알고리즘에서 "지금 로드할 수 있는 모드 중 id가 서수상 가장 작은 것"을 먼저 둔다. 위 예는 `b z a`.

**이유:** 결정적이고 입력 순서와 무관하며 의존성을 항상 지킨다.

**상태:** 확인
