**위치:** S1 ⑤⑥ 스키마가 선언한 `default` 값의 검사 (G69 보강)

**무엇이 비어 있었나:** ⑤ 링크와 ⑥ 검증은 ④의 최종 값(기본값 없음)만 봐서, 스키마 `default`는 어느 단계도 검사하지 않은 채 동결본에 완성된 값으로 채워졌다(`default="Nope"`, `default=500`에 `max=100`, `int`에 `default=1.5`가 모두 통과).

**어떻게 정했나:** 스키마 선언의 `default` 값은 Def 값과 **같은 규칙**(존재·타입·보이는 범위·`abstract` 금지, 타입·`min`/`max`)으로 **선언마다 한 번** 검사한다. 책임은 그 값을 선언한 모드(`extend`면 확장한 모드)이고 위치는 선언의 키워드 인자다. 보이는 범위는 선언한 모드 기준이다. `field`의 함수 기본값(`default=lambda ...`)은 엔티티를 만들 때 계산하는 식이라 검사하지 않는다(G33).

**이유:** 동결본이 “검증을 마친 완성된 값”이라고 내세우려면 기본값도 검증을 거쳐야 한다. Def마다 반복하면 같은 오류가 Def 수만큼 나온다.

**상태:** 확인
