**위치:** S1 ②a 스키마 파일

**무엇이 비어 있었나:** 스키마 파일을 어떻게 가려내는지("예: 모드 폴더의 `schema/`")가 예시로만 있었다.

**어떻게 정했나:** `use(...)`/`use_all(...)` 목록을 파일 단위로 편 뒤, 경로가 `schema/`로 시작하는 파일은 ②a, 나머지는 ②b. 각 묶음 안에서는 목록 순서. mod.py 문법은 그대로. 대소문자만 다른 `Schema/`는 `LOD001`.

**이유:** S1의 "파일 실행 순서는 `use`로 명시"와 "mod.py는 AST로만 읽는다"를 둘 다 지킨다. 별도 `use_schema`는 문법을 늘리고, 자동 발견은 명시 원칙에서 벗어난다.

**상태:** 확인
