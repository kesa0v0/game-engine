**위치:** S1 ⑥ 동결 집합과 `abstract` Def (G57·G66 보강)

**무엇이 비어 있었나:** 동결 후 런타임의 Def 목록에 `abstract` Def가 들어가는지, 동결본이 어디에 놓이는지 없었다.

**어떻게 정했나:** 동결 집합 `DefSet`에는 **`abstract`가 아닌 Def만** 들어간다(등록 순서, id 조회, 타입별 목록). `abstract` Def는 상속을 펼친 결과(`Expanded`)와 덤프(S9)에만 남는다. 최종 `ContentLoadResult`는 `Frozen`(`DefSet`)을 내놓고, `Expanded`는 출처 덤프용으로 그대로 둔다. 동결본의 부모는 id 문자열로 가리킨다(부모가 `abstract`면 동결 집합에 없으므로).

**이유:** 런타임이 타입의 모든 Def를 순회할 때 템플릿이 섞이면 거르는 쪽이 빠뜨릴 때마다 엔티티가 잘못 만들어진다. 아무도 가리킬 수 없는 Def(G66)는 런타임이 알 이유가 없다.

**상태:** 확인
