**위치:** S1 ⑥ `keys="all"` 키 컴포넌트의 줄과 기본값 (G69·G74 보강)

**무엇이 비어 있었나:** `keys="all"`(기본)은 키 타입 Def마다 줄이 있다는 뜻인데, 아무도 그 줄을 다 쓰지 않고 `const` 멤버에 기본값이 없으면 줄을 읽을 때 값이 없다. 동결본에도 줄이 없어 G69의 “구멍 없음”과 어긋났다.

**어떻게 정했나:** **(a)** `keys="all"` 키 컴포넌트의 `const` 멤버는 기본값이 있어야 한다(리스트·맵 제외, G74와 같은 규칙). 없으면 선언한 모드의 스키마 오류(`SCH004`, `default=`를 주거나 `keys="listed"`를 쓰라는 안내). **(b)** 동결본은 적힌 줄만 저장한다. `FrozenDef.TryGetRow(컴포넌트, 키)`는 적힌 줄이면 그 줄을, `keys="all"`이면 **키 타입의 구체 Def**에 한해 적히지 않은 줄을 `const` 기본값으로 채워 돌려준다. `abstract`나 다른 타입이나 없는 Def의 키, 그리고 `keys="listed"`에서 적히지 않은 줄은 없는 값이다(false). `field` 멤버는 값이 적혀 있을 때만 있다. 덤프(G76)는 적힌 줄만 낸다.

**이유:** 줄을 Def 수 × 키 Def 수만큼 미리 만들면 메모리가 크다. 읽을 때 기본 줄을 돌려주면 저장은 그대로이고 “읽을 때 값이 항상 있다”가 참이다.

**상태:** 확인
