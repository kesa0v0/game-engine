**위치:** X2 마감만 있고 `on_timeout=`이 없는 질문

**무엇이 비어 있었나:** G161은 `on_timeout=`이 마감을 요구한다고 했지만 반대(마감이 있는데 기본 답이 없음)는 정하지 않았다. 그대로 두면 마감이 지나도 아무 일도 없이 열려 있다.

**어떻게 정했나:** **실행 오류다: `deadline=`을 쓰면 `on_timeout=`도 적는다.** 마감이 지나면 무슨 일이 일어나는지가 늘 스크립트에 보인다. 그냥 넘기기를 원하면 그런 선택지를 두고 기본 답으로 지정한다.

**이유:** "아무도 답하지 않음" 값(B)은 처리를 빠뜨리면 `None`으로 뒤에서 오류가 난다. 질문을 닫고 Flow를 끝냄(C, RimWorld 선택 편지가 사라지는 것과 비슷)은 뒤의 코드가 왜 안 돌았는지 헷갈린다. 마감을 정보로만 둠은 X2의 "마감 시 기본 응답 주입"과 맞지 않는다. 막는 쪽이 나중에 B·C를 더해도 기존 모드가 깨지지 않는다. 일반적인 설계 판단이다.

**상태:** 확인
