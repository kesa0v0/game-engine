**위치:** G334에서 이어서: 반올림 규칙

**무엇이 비어 있었나:** `maximumFractionDigits`가 자리를 자를 때 남는 자리를 어떻게 할지 정하지 않았다.

**사례:** 로직 언어의 `round`는 0에서 먼 쪽(G97). `Intl.NumberFormat`의 기본 `halfExpand`도 0에서 먼 쪽이다(일반 지식). .NET `Math.Round`의 기본은 짝수 쪽이다.

**어떻게 정했나 (사용자가 고름):** 0에서 먼 쪽(2.5 → 3, -2.5 → -3). 값은 소수 6자리의 정확한 수이므로 정수로 계산한다. 반올림해 0이 된 음수(-0.4 → 0)는 `-0`이 아니라 `0`이다.

**이유:** 모드가 `round`로 계산한 값과 화면에 보이는 값이 같다. 버림 등이 필요해지면 `roundingMode` 옵션을 더해도 G356(모르는 옵션은 오류) 덕에 기존 번역과 부딪히지 않는다.
