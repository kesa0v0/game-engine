**위치:** S1 ⑥ 작성용 `.pyi`의 모양 (G71 보강)

**무엇이 비어 있었나:** 스텁이 어떤 파이썬 선언으로 나오는지(인자의 필수 여부, `fixed`, 함수 자리 타입) 없었다.

**어떻게 정했나:** **Def 타입은 클래스 하나**(타입이자 생성자): `def __init__(self, id: str, *, parent=..., abstract: bool = False, override: bool = False, <const>..., <컴포넌트>...)`(`parent`는 같은 타입의 보이는 Def id의 `Literal`이거나 없음). 컴포넌트도 클래스 하나(`__init__(self, *, 값...)`), 키 컴포넌트는 Def 인자에서 `dict[Literal[키 타입 Def id], 컴포넌트]`. **값 인자는 모두 선택(`= ...`)이다**: 필수 여부는 상속·기본값·패치로 정해져 정적으로 알 수 없으므로 ⑥(`VAL001`)이 본다. `fixed`는 정수 또는 소수를 받는 별칭(`type fixed`), `TextKey`는 문자열 별칭이다: 정수와 소수 리터럴을 받고 정밀도 검사는 엔진이 한다(G48). `DefId[X]`는 보이는 **구체** X Def id의 `Literal[...]`(abstract 제외, G66; 없으면 `Never`). `Cond`·`Action` 자리는 `Callable[..., bool]`·`Callable[..., None]`로 느슨하게 둔다(타입 이름과 서명이 미정, G24). `derived`와 `ref` 칼럼, 엔티티 키 컴포넌트는 작성용 스텁에 없다. 모드가 보는 범위(필수 의존의 닫힘)의 타입·컴포넌트·`const`·Def id만 낸다. `patch.set/add/append/remove`는 `def_id: Literal[보이는 Def id]`, `mod_loaded(mod: Literal[선언한 모드 id])`, `inherit: Any`가 함께 나온다.

**이유:** 필수로 만들면 `abstract` 부모를 쓰는 자식이 거짓 오류를 낸다. 래퍼 클래스 `fixed`는 소수를 쓸 때마다 감싸야 해서 작성이 불편하다. 함수 서명은 로직 슬라이스에서 좁힌다.

**상태:** 확인

**바뀜:** Def id `Literal`에는 내 모드의 짧은 이름과 보이는 모든 전체 이름이 함께 든다 → G265.
