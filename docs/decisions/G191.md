**위치:** S2 최상위 콘텐츠 파일의 컴프리헨션 (G189에서 이어짐)

**무엇이 비어 있었나:** G189는 함수 본문의 컴프리헨션만 정했다. Def 파일 최상위(`Unit("X", tags=[t for t in ...])`)는 정하지 않았다.

**어떻게 정했나:** **최상위에서는 로드 오류(`EVL002`)로 둔다.** G102가 최상위의 `for`·조건식을 막은 것과 같다. 필요해지면 그때 연다.

**이유:** 콘텐츠 파일은 값을 그대로 적는 곳이라 계산은 `def`·람다로 옮긴다.

**상태:** 확인
