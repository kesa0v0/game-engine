**주제:** 엔티티가 자기 Def id를 읽는 속성 `defid` (사용자 제안 2026-10-21, Pandemic 예시를 만들다 드러남).

**결정:** 엔티티에서 `e.defid`는 그 엔티티를 만든 Def의 전체 이름(`pandemic:Atlanta`)이다. 값은 Def id 값(`DefId`)이라 `defid("Atlanta")`와 비교하고, 맨 리터럴과 비교하면 `LNK005` 경고다(G261). 컴포넌트·Def 타입 이름은 대문자로 시작하는 관례라 부딪히지 않고, 같은 이름의 컴포넌트가 있으면 컴포넌트가 먼저다(`entity`가 멤버 뒤인 것과 같은 순서). 스텁은 그 Def 타입의 구체 Def id 리터럴을 돌려주는 읽기 속성으로 적는다. 호스트의 `World.DefOf`와 같은 값이다.

**이유:** 지도 도시처럼 Def가 곧 정체성인 엔티티를 이름으로 찾으려면 엔티티에서 Def id를 읽어야 하는데 스크립트에는 방법이 없어, 같은 값을 필드에 따로 적어 두는 중복이 필요했다.

**상태:** 확인
