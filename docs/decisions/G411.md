**위치:** G410에서 이어서: `<space>`를 적는 파일

**무엇이 비어 있었나:** 공간 선언(G410)도 그림 정의(G409)처럼 호스트가 읽는 XML인데, 같은 파일에 둘지 따로 둘지 없었다.

**어떻게 정했나 (사용자가 고름):**

- 공간은 `.space.xml` 파일에, 그림 정의는 `.look.xml` 파일에 적는다. 서로의 요소를 넣으면 로드 때 진단한다.
- 폴더는 G409와 같이 자유이고 관례는 `looks/` 아래다.

고른 것: 따로 `.space.xml`(이것), `.look.xml` 안에 함께(파일 종류가 하나지만 이름과 내용이 어긋남).

**이유:** 파일 이름만 보고 종류를 안다(G409와 같은 까닭). 그림만 고치는 모드가 공간 파일을 건드리지 않는다. 패러독스도 지도 설정과 그림 정의를 다른 파일 종류로 나눈다(일반 지식).

**상태:** 확인
