**위치:** S1 ⑥ `.pyi` 스텁의 범위와 생성 방식 (schema-design 4.3 보강)

**무엇이 비어 있었나:** `.pyi`가 담을 것이 작성용(Def·컴포넌트 생성자, id `Literal`, `patch`)과 로직용(엔티티 접근, `derived`, `ref` 칼럼, 함수 서명)으로 나뉘는데 이 슬라이스가 어디까지인지, 어떻게 만드는지 없었다.

**어떻게 정했나:** 이번에는 **작성용만** 만든다. 로직용은 엔티티 모델이 생기는 로직 슬라이스에서 같은 생성기에 더한다. 생성기는 **순수 함수** `StubGenerator.Generate(모드 id, 로드 결과) → 문자열`이고, 파일 배치·`pyrightconfig.json`(Python 3.12)·`engine check` 명령은 CLI를 만들 때 정한다.

**이유:** 작성용은 지금 있는 데이터(스키마, 보이는 범위, Def id)만으로 완성된다. 로직용은 아직 없는 엔티티 모델에 의존해 지금 모양을 정하면 뒤집힐 가능성이 크다.

**상태:** 확인
