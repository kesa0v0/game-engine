**위치:** G326에서 이어서: 월드 표시의 값(G389·G394)이 호스트로 나가는 모양

**무엇이 비어 있었나:** 경계의 값은 닫힌 목록이라 호스트가 그 목록만 알면 어떤 값이든 받는다. `look(…)`과 자리 값은 그 목록에 없다.

**어떻게 정했나 (사용자가 고름):**

- `BridgeLook`: 그림 이름과 키 순 키=값(값은 기존 경계 값).
- `BridgeWhere`: 세 모양 중 하나. At(공간 이름 또는 기본 공간, 값), On(엔티티, 붙는 곳 이름), Between(자리, 자리: 자리 값 둘, 공간을 건너도 됨). 커널의 `at`·`on`·`between`이 만든다(G394).
- 일반 화면 함수도 이 값을 돌려줄 수 있다(초상화 패널, "그 칸으로 카메라 이동" 같은 버튼).

고른 것: 새 종류(이것), 예약 키 사전(`{"$look": …}`, 문자열 검사와 모더 키 충돌), 그림만 값 종류이고 자리는 월드 물체 결과의 칸(나중에 늘리면 모든 호스트가 바뀜).

**이유:** `option(…)`이 `BridgeOption`이 된 선례(G271)와 같다. 닫힌 목록은 나중에 늘리는 쪽이 지금 늘리는 쪽보다 비싸고, 호스트는 문자열 대신 타입으로 구별한다.

**상태:** 확인

**바뀜:** `BridgeWhere`의 On 모양은 Attach, 커널의 `on(…)`은 `attach(…)` → G404.
