**위치:** G394·G410에서 이어서: 네모 칸 공간 종류의 자리 값과 설정

**무엇이 비어 있었나:** `at("square", [2, 3])`을 그리려면 자리 값의 숫자가 Unity의 어느 축으로 가는지 정해야 했다. Unity의 2D 그림은 x·y 평면, 3D 바닥은 x·z 평면이다. 사용자는 xyz(높이)도 받을 수 있느냐고 물었다.

**어떻게 정했나 (사용자가 고름):**

- 종류 하나 `grid`. 자리 값은 정수 두 개나 세 개의 목록이다. 모드의 뜻은 늘 "판 위 가로 x, 세로 y, 높이 z"다.
- `cell`: 한 칸 크기(기본 1). `origin`: `[0, 0]` 칸의 중심이 놓일 곳(기본 원점).
- `plane="xy"`(기본, 2D): 모드 x → Unity x, y → Unity y(z를 2D에서 어떻게 보일지는 쓸 곳이 생길 때 정한다). `plane="xz"`(3D 바닥): 모드 x → Unity x, y → Unity z, z → Unity y.
- `flip-y="true"`: 모드 y가 커지면 화면 아래(또는 뒤)로 간다.
- 공간 종류와 그림·공간 정의 파일은 Unity 패키지의 형식이다. spine S10 2항("UI 정의 파일은 호스트마다 제 형식")대로 다른 호스트와 맞출 약속은 두지 않는다.

고른 것: `grid` 하나 + `plane`(이것), `grid2d`·`grid3d` 둘(2D에서 높이, 3D에서 두 숫자를 쓰기 어려움).

**이유:** 모드 좌표의 뜻을 하나로 두고 2D·3D 화면의 차이를 설정 하나에 모아 모더가 덜 헷갈린다.

**상태:** 확인
