**위치:** S1 패치 호출 모양

**무엇이 비어 있었나:** `patch.set/add/append/remove`의 호출 모양, 대상과 필드를 가리키는 방법이 spec·schema-design 어디에도 없었다.

**어떻게 정했나:** 문자열 둘: `patch.set("Scout", "Health.base_max", 20)`. 첫 인자는 Def id 문자열(S2 "Def 참조는 문자열"과 같음), 둘째는 점 경로 문자열(컴포넌트가 있으면 `컴포넌트.필드`, const면 이름만, 키 컴포넌트는 `Skill.Medicine.level`). 새 문법 없음. 검사는 호출 인자 모양 → ②b, 대상·필드 존재 → ③, 값 타입 → ⑥. 경로 해석은 S3와 같은 코드를 쓴다.

**이유:** 문법을 늘리지 않고, Def 참조가 문자열이라는 기존 결정과 맞으며, `.pyi`가 id를 `Literal`로 검사할 수 있다. 생성자 모양(B)은 Def를 만드는 호출과 구분되지 않고, 핸들(C)은 v1에 과하다.

**상태:** 확인

**바뀜:** 첫 인자의 Def id는 G261대로 푼다. `:`가 없으면 패치하는 모드 기준이라, 기본 게임의 Def는 `patch.set("core:Scout", "Health.base_max", 20)`로 적는다.
