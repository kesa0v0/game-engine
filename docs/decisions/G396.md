**위치:** G395에서 미룬 것: 표시 목록을 견줄 때 같은 표시를 알아보는 법

**무엇이 비어 있었나:** 지웠다 다시 만들면 깜빡이고 진행 중인 애니메이션이 처음부터 다시 시작한다. 사거리가 바뀐 사거리 원은 같은 원의 크기만 고쳐야 하고, 대상이 바뀐 공격 화살표는 게임마다 새 화살표로 보거나 옮겨 가게 하고 싶다.

**어떻게 정했나 (사용자가 고름):**

- 자동 열쇠: 그림 이름 + 놓을 곳. 그림 값의 키=값(`radius` 등)이 바뀌어도 같은 표시로 보고 고친다. 후보 칸 하나가 빠져도 나머지는 그대로다.
- `key=`를 적으면 그것이 열쇠다. 놓을 곳이 바뀌어도 같은 표시로 이어 간다(화살표가 옮겨 감).
- 열쇠가 겹치면 순번을 덧붙여 가른다. 열쇠는 그 표시를 낸 함수 안에서만 센다.

고른 것: 순번만(앞이 빠지면 뒤가 모두 엉뚱하게 고쳐짐), 자동 열쇠 + `key=` 덮기(이것), `key=` 필수(대부분 번거로움).

**이유:** 대부분의 표시는 열쇠를 적지 않아도 바르게 고쳐지고, 옮겨 가는 애니메이션처럼 원하는 게 다를 때만 적는다. 화면 UXML `for`가 엔티티는 id, 글자·정수는 값, 그 밖은 순번으로 알아보는 것(`UiValues.RepeatKey`)과 같은 생각이고, React `key`도 같은 문제를 푼다(일반 지식).

**상태:** 확인
