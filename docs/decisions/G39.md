**위치:** S1 패치 값의 검사 시점

**무엇이 비어 있었나:** 패치한 값의 타입을 ③에서 보는지 ⑥까지 미루는지가 없었다.

**어떻게 정했나:** 값의 **모양**은 ③에서 적용 전에 검사하고 패치 호출 줄로 보고한다(`int` 필드에는 `int`, 리스트에는 원소 타입의 값, `DefId[...]`에는 문자열 등). 범위(`min`/`max`), 합산 결과의 오버플로, 가리키는 Def id의 존재는 ⑤·⑥에서 최종 값으로 검사한다. `int` → `fixed`는 허용, `fixed` → `int`는 오류(데이터 값 규칙은 G48). 모양 오류가 난 패치는 적용하지 않고 건너뛴다(같은 필드의 연쇄 오류를 내지 않기 위해).

**이유:** 모양 오류는 호출 자체의 문제라 호출 줄에서 잡아야 위치가 정확하고 ④에서 자식으로 퍼지지 않는다. 범위·존재는 여러 `add`의 합과 `inherit`가 정해진 뒤여야 하므로 G25의 "값 검사는 최종 값으로"와 같다.

**상태:** 확인
