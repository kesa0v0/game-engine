**위치:** S1 중복 Def ID

**무엇이 비어 있었나:** ID가 타입별로 하나인지 전체에서 하나인지.

**어떻게 정했나:** 타입과 무관하게 **전역에서 하나**. 같은 모드나 의존 관계가 있는 모드끼리면 나중 것만 `DEF001`(의존 대상이면 "override=True" 안내). 서로 의존하지 않는 두 모드면 둘 다 오류(둘 다 비활성화).

**이유:** S1의 `defs["Name"].field`가 타입 없이 이름으로 찾는다. 독립 모드끼리는 어느 쪽이 맞는지 근거가 없다(G10과 같은 해석).

**상태:** 잠정

**바뀜:** Def id의 첫 조각이 만든 모드의 id로 강제되어 서로 다른 모드가 같은 id를 새로 만드는 일이 없어졌다(남의 id는 `override=True`만) → G258.
