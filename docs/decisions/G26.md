**위치:** S1 ② 단계 분리

**무엇이 비어 있었나:** spec은 "스키마 파일에서 Def 생성은 오류"만 말했다. 반대 방향은 없었다.

**어떻게 정했나:** Def 파일에서 스키마 함수(`deftype`, `const` 등)나 타입 이름(`int` 등)을 쓰면 `SCH007`. 스키마 파일에서 Def 생성자나 컴포넌트 값은 `SCH006`. 스키마 파일에서 묶은 별칭(`T = list[str]`)은 같은 모드의 Def 파일에서도 이름으로 보이지만(G20), Def 값으로 쓰면 `SCH007`이다. Def 값은 리스트·맵 안까지 데이터여야 한다. Def 핸들, 제자리가 아닌 컴포넌트 값, 호출하지 않은 생성자는 `DEF003`.

**이유:** Def 파일에서 타입을 선언하면 그 타입은 이미 고정된 뒤라 4.1의 문제가 되살아난다.

**상태:** 잠정
