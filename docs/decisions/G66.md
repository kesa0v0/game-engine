**위치:** S1 ⑤ `abstract` Def를 가리키는 참조 (G57 보강)

**무엇이 비어 있었나:** `abstract=True` Def는 엔티티를 만들 수 없는데, `DefId` 값이나 키 컴포넌트 줄 키가 그것을 가리키면 어떻게 할지 없었다.

**어떻게 정했나:** `abstract` Def를 가리키면 오류다(“abstract Def는 템플릿이라 가리킬 수 없다. 구체 Def를 쓰세요”). `DefId` 값(리스트·맵 안, 맵 키 포함)과 키 컴포넌트의 줄 키에 적용하고, `parent`는 ④가 따로 해석하므로 해당 없다.

**이유:** 가리키는 목적은 거의 항상 구체 Def다. 지금 막아 두면 나중에 푸는 것은 호환되지만, 풀어 둔 것을 막으면 기존 모드가 깨진다.

**상태:** 확인
