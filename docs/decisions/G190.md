**위치:** S3 전역 순회 `all(Type)`과 파이썬 `all(xs)`의 이름 충돌 (G189에서 이어짐)

**무엇이 비어 있었나:** spec S3는 엔티티 전역 순회를 "명시적 `all(Type)`"으로 적었는데 G189가 파이썬 뜻의 `all(xs)`를 내장으로 더해 같은 이름이 두 뜻이 된다.

**어떻게 정했나:** **`all`은 파이썬 뜻으로 둔다. 엔티티 전역 순회는 만들 때 다른 이름으로 정한다.** spec S3의 `all(Type)`은 이름이 아니라 "전역 순회는 명시적 호출로만"이라는 규칙으로 읽는다.

**이유:** 인자 종류로 나누는 안(`all(Unit)`은 목록, `all([...])`는 참/거짓)은 한 이름이 두 뜻이라 헷갈린다. 파이썬 `all`을 빼는 안은 파이썬을 아는 모더의 기대와 어긋난다.

**상태:** 확인
