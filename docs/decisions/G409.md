**위치:** G390이 미룬 것: 그림 정의 파일의 폴더와 확장자

**무엇이 비어 있었나:** G390은 그림 정의를 그냥 XML로 두고 폴더·확장자를 화면 UXML과 나눈다고만 했다. 모더가 만드는 파일의 이름 규칙이라 계약이다.

**어떻게 정했나 (사용자가 고름):**

- 확장자 `.look.xml`인 파일이 그림 정의다. 모드 안 어느 폴더에 있어도 읽는다.
- 관례는 `looks/` 아래에 두는 것이고 예제와 모더 문서가 그렇게 쓴다(`core/looks/units.look.xml`).
- 편집기는 `.xml`로 알아봐 XML 지원을 그대로 쓴다.

고른 것: 폴더 `looks/`에 `.xml`(폴더가 종류를 정함), 폴더 자유에 `.look.xml`(이것), 폴더 `looks/`에 `.look`(편집기 설정이 따로 필요).

**이유:** 파일 이름만 보고 종류를 알 수 있고 옮겨도 뜻이 바뀌지 않는다. 폴더는 관례로 맞춰 찾기 쉽게 한다.

**상태:** 확인
