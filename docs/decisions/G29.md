**위치:** S1 매니페스트 `extensions`

**무엇이 비어 있었나:** spec은 `Mod(...)`에 `extensions`가 있다고 했지만 ① 구현에는 없다.

**어떻게 정했나:** 이번 단계도 넣지 않았다. 외부 값 타입(`spatial.Point`)은 스키마에서 아직 쓸 수 없다(속성 접근이 `EVL002`).

**이유:** `ext.*` 확장 API 모양이 열린 질문이다. 커널 확장을 붙일 때 함께.

**상태:** 잠정
