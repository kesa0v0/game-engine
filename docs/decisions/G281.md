**위치:** G277에서 이어서: `ui_state` 이름의 이름 공간 (구현하며 드러남)

**무엇이 비어 있었나:** 같은 모드에 `component("Selection", …)`와 `ui_state("Selection", …)`가 함께 있을 때 어떻게 되는지 정하지 않았다. UI 기록은 `ui.Selection`으로만 쓰이지만 스텁(`.pyi`)에서는 둘 다 `class Selection`이 된다.

**어떻게 정했나:** UI 기록 이름은 Def 타입·컴포넌트·신호와 한 이름 공간이다. 겹치면 `SCH` 이름 중복 오류(한 모드면 "declared more than once", 여러 모드면 충돌 오류)다. Def 타입·컴포넌트 자리에 UI 기록 이름을 쓰면 "is a UI state, not a …"로 알린다.

**이유:** 따로 두면 스텁 클래스 이름을 `UiSelection`처럼 바꿔 내야 하고 읽는 사람도 헷갈린다. 신호도 이미 같은 이름 공간이다(G145).

**상태:** 확인
