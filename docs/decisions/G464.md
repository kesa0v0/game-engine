**위치:** G462에서 이어서: 못 보는 컴포넌트를 복사본에서 어떻게 두나

**무엇이 비어 있었나:** G462는 "붙지 않은 채"라고 했지만 Def 타입에 든 컴포넌트는 판에서 뗄 수 없다(S4). 값을 기본값으로 되돌리면 "모른다"와 "정말 그 값"(전염 카드의 `city=None`)을 가릴 수 없고, 블록 밖의 거른 읽기(`card.Face`가 None)와 어긋난다.

**어떻게 정했나 (사용자가 고름):**

```python
with imagine():
    for c in query(InfectionCard):
        if c.Face is None:
            attach(c, Face(city=guess(c)))
    play("EndTurn", player=me)
```

- None은 블록 안팎에서 "모른다" 하나의 뜻이다. 플레이어 화면의 규칙(G198)과 같다.
- 채우지 않은 숨긴 곳을 커맨드가 건드리면 None을 읽는 오류가 `r.error`로 온다.
- 숨김 표시는 시험 판의 것이라 저장되지 않고, 안쪽 블록의 복사에는 그대로 따라간다.

**버린 것:** 기본값으로 되돌리기(모름과 기본값을 못 가림), 런타임에 붙인 것만 떼고 Def 컴포넌트는 기본값(규칙이 둘).

**이유:** 블록 밖과 안에서 숨김이 같은 모양이고, 추측을 넣는 길이 이미 있는 `attach` 하나다.
