**위치:** S1 `add`의 기준값 (G42 보강)

**무엇이 비어 있었나:** 필드에 아무도 값을 적지 않았는데 `add`가 오면 무엇에 더하는지 없었다.

**어떻게 정했나:** 기준값은 **상속과 스키마 `default`까지 합친 그 시점의 현재 값**이다(`move=const(int, default=1)`에 값이 없고 `patch.add("Scout", "move", 2)`이면 3). 값도 `default`도 없는 필드(필수)에 `add`가 오면 기준값이 없으므로 오류이고 `set`을 안내한다.

**이유:** 모더가 보는 값은 상속과 기본값이 섞인 값이라 "그 값에 더한다"가 직관과 맞고, 적용 순서(G50)가 정해져 있어 결과가 하나로 정해진다. 직접 적은 값만 보면 `default`가 있어도 `add`가 막히고, 0에서 시작하면 `default`의 의미가 사라진다.

**상태:** 확인
