# spec 빈틈 목록

`spine-spec.md` 8절의 절차에 따라, 구현하다 spec이 비어 있거나 애매한 곳을 만나면 여기에 적는다. 추측으로 채운 곳도 반드시 적는다. 구현이 끝나면 각 항목을 spec의 결정으로 옮기고 이 목록에서 지운다.

**상태:** 잠정 = 구현이 이렇게 동작하지만 확인 필요 · 확인 = 사용자가 동의함 · 반영 = spec에 옮김.

**모양:** 이 파일은 색인이다. G 번호마다의 전문(무엇이 비어 있었나·어떻게 정했나·이유)은 `docs/gaps/`의 영역 파일에 있다. 새 항목은 그 영역 파일 끝에 `## G번호` 절(위치·무엇이 비어 있었나·어떻게 정했나·이유·상태)을 쓰고 이 색인의 그 영역 표에 한 행을 더한다. 번호는 영역과 상관없이 전체에서 이어 매긴다(다음 번호는 G229). 영역은 위치의 첫 표시로 고르고, 다른 G에서 이어진 항목은 그 G의 영역에 둔다. 색인의 "무엇을 정했나"는 영역 파일의 "어떻게 정했나"를 줄인 것이고(2026-10-18), 새 항목도 한두 문장으로 적는다. 요약과 전문이 다르면 전문이 맞다.
